# ✈️ Skyscanner Price Tracker — Χανιά ⇄ Αθήνα

Προσωπική πλατφόρμα που:

1. **Κάθε 6 ώρες** τραβάει από το **Skyscanner** τις τιμές όλων των απευθείας πτήσεων
   Χανιά→Αθήνα και Αθήνα→Χανιά για **σήμερα + 10 μέρες**,
2. κρατάει το **ιστορικό τιμής κάθε πτήσης** (ποια πτήση, ποια ώρα, πόσο κόστιζε κάθε φορά),
3. **προβλέπει με AI** την τιμή για κάθε επόμενο 6ωρο μέχρι την αναχώρηση και σου λέει
   **«Αγόρασε τώρα» / «Περίμενε» / «Αμφίρροπο»**,
4. ένας **AI αναλυτής (Claude)** γράφει σε κάθε ενημέρωση ανάλυση στα ελληνικά: γενική εικόνα,
   καλύτερες επιλογές τώρα, σχόλιο για κάθε μέρα και κάθε πτήση,
5. τα δείχνει σε **dashboard με διαγράμματα** (κινητό και υπολογιστή).

Τρέχει δωρεάν στο **GitHub** (Actions + Pages). Το μόνο κόστος είναι η πρόσβαση στο Skyscanner μέσω Apify.

---

## Από πού έρχονται τα δεδομένα

Το Skyscanner **δεν δίνει API σε ιδιώτες**. Το επίσημο Travel API δίνεται μόνο σε εγκεκριμένους
εμπορικούς partners. Γι' αυτό χρησιμοποιείται το **Apify**, μια υπηρεσία που εκτελεί την ίδια
αναζήτηση που κάνεις εσύ στο skyscanner.net (με residential proxies, γιατί το Skyscanner μπλοκάρει
servers) και επιστρέφει τα αποτελέσματα ως δεδομένα:

- actor: [`memo23/skyscanner-scraper`](https://apify.com/memo23/skyscanner-scraper) (αλλάζει στο `config.yaml`)
- αγορά `GR`, νόμισμα `EUR`, 1 ενήλικας, economy, μόνο απευθείας πτήσεις
- ανά πτήση κρατιέται η **φθηνότερη** τιμή που δείχνει το Skyscanner (από όποιο πρακτορείο/αεροπορική)

**Κόστος AI αναλυτή (Claude):** ~18 χιλ. tokens εισόδου + ~6 χιλ. εξόδου ανά ενημέρωση →
περίπου 0,10 $ με Sonnet 5.5 (**~12 $/μήνα**) ή ~0,05 $ με Haiku 4.5 (**~6 $/μήνα**, αλλάζει στο `config.yaml`).

**Κόστος Skyscanner/Apify:** ~0,22 $ ανά συλλογή (22 αναζητήσεις) → **~25–30 $/μήνα** για 4 συλλογές τη μέρα.
Οι λογαριασμοί Apify έχουν 5 $ δωρεάν τον μήνα. Υπάρχει όριο ασφαλείας `max_charge_usd_per_run`
στο `config.yaml`. Για λιγότερο κόστος μείωσε το `days_ahead` ή τις συλλογές στο workflow.

> Σημείωση: η αυτοματοποιημένη ανάγνωση του Skyscanner μέσω τρίτων δεν είναι επίσημα εγκεκριμένη
> από το Skyscanner. Είναι για προσωπική χρήση και με χαμηλή συχνότητα (4 φορές τη μέρα).

## Εγκατάσταση (≈10 λεπτά, μία φορά)

1. **GitHub repo** → φτιάξε νέο repository (π.χ. `flight-prices`) και ανέβασε όλα τα αρχεία αυτού του φακέλου.
   - Με **δημόσιο** repo το GitHub Pages είναι δωρεάν.
   - Για **ιδιωτικό** repo με Pages χρειάζεται GitHub Pro, που οι φοιτητές το παίρνουν δωρεάν
     μέσω του [GitHub Student Developer Pack](https://education.github.com/pack).
2. **Apify token** → φτιάξε λογαριασμό στο [apify.com](https://apify.com), και πήγαινε
   *Settings → API & Integrations* → αντέγραψε το **Personal API token**.
3. Στο repo: **Settings → Secrets and variables → Actions → New repository secret**
   - Name: `APIFY_TOKEN`, Value: το token.
4. *(Προαιρετικό, για τον AI αναλυτή)* Φτιάξε κλειδί στο [platform.claude.com](https://platform.claude.com)
   και πρόσθεσέ το ως secret `ANTHROPIC_API_KEY`. Χωρίς αυτό, η ανάλυση γίνεται με απλούς κανόνες.
5. Στο repo: **Settings → Pages → Build and deployment → Source: _GitHub Actions_**.
6. **Actions → «Συλλογή τιμών & πρόβλεψη» → Run workflow** για την πρώτη συλλογή.
   Από εκεί και πέρα τρέχει μόνο του κάθε 6 ώρες.
7. Άνοιξε το dashboard: `https://<username>.github.io/<repo>/`
   - Demo με προσομοιωμένα δεδομένα: `https://<username>.github.io/<repo>/?demo=1`

Το GitHub μπορεί να καθυστερήσει τα προγραμματισμένα workflows 5–30 λεπτά. Το μοντέλο το λαμβάνει υπόψη.

## Τι βλέπεις στο dashboard

- **Διαδρομή** (Χανιά→Αθήνα / Αθήνα→Χανιά), **βήμα πρόβλεψης** (6/12/24 ώρες), **Επερχόμενες / Παρελθόν**.
- **Ημερολόγιο**: για κάθε μέρα η φθηνότερη τιμή και πόσο άλλαξε σε 24 ώρες.
- **Διάγραμμα «Φθηνότερη τιμή της ημέρας διαχρονικά»**.
- **Λίστα πτήσεων**: ώρα, αεροπορική, αριθμός πτήσης, τρέχουσα τιμή, αλλαγή 24ω, mini-διάγραμμα, σύσταση.
- **Ανά πτήση**: διάγραμμα με **όλο το ιστορικό τιμής** (συνεχής γραμμή) και **την πρόβλεψη μέχρι
  την αναχώρηση** (διακεκομμένη γραμμή + ζώνη εύρους 80%), πίνακας πρόβλεψης ανά 6/12/24 ώρες,
  πλήρης πίνακας ιστορικού, χαμηλότερη/υψηλότερη τιμή, πιθανότητα πτώσης.
- **«Πόσο αξιόπιστη είναι η πρόβλεψη;»**: πόσα € πέφτει έξω κατά μέσο όρο σε δεδομένα που δεν είχε δει.

## Πώς γίνεται η πρόβλεψη

**Δεδομένα εκπαίδευσης.** Κάθε 6 ώρες γράφεται η τιμή κάθε πτήσης. Από το ιστορικό
φτιάχνονται ζευγάρια «τιμή σε χρόνο *t* → τιμή της ίδιας πτήσης *h* ώρες αργότερα»
(h = 6, 12, …, 240). Μετά από λίγες εβδομάδες είναι εκατοντάδες χιλιάδες τέτοια ζευγάρια.

**Τι λαμβάνεται υπόψη:** ώρες μέχρι την αναχώρηση, πόσο μπροστά προβλέπουμε, ημέρα εβδομάδας
και ώρα πτήσης, αεροπορική, διαδρομή, πρόσφατη τάση (τελευταίο 6ωρο / 24ωρο), πόσο απέχει η
τιμή από το ελάχιστο και το μέγιστο που είχε η πτήση, πόσο ακριβότερη είναι από τη φθηνότερη
πτήση της ίδιας μέρας.

**Μοντέλα πρόβλεψης.** Σε κάθε ενημέρωση εκπαιδεύονται όλα και επιλέγεται αυτόματα το πιο ακριβές στο backtest:

| Μέθοδος | Τι κάνει |
|---|---|
| Αρχική υπόθεση | πρώτες ~2 μέρες, όταν δεν υπάρχουν δεδομένα: ουδέτερη πρόβλεψη με μεγάλη αβεβαιότητα |
| Εμπειρικό (στατιστική) | κατανομή των πραγματικών μεταβολών ανά «ώρες πριν την πτήση × ορίζοντα» |
| **AI k-NN «παρόμοιες περιπτώσεις»** | βρίσκει στο ιστορικό τις 80 καταστάσεις που μοιάζουν περισσότερο με την τωρινή και κοιτάζει τι έγινε μετά |
| **AI Gradient Boosting** | machine learning (quantile regression) με όλα τα χαρακτηριστικά· ενεργοποιείται μετά από ≥ 7 μέρες δεδομένων |
| **AI Ensemble** | μέσος όρος των παραπάνω· συνήθως το πιο σταθερό |

**Έξοδος:** για κάθε 6ωρο τρία νούμερα. Η **πιθανότερη** τιμή (διάμεσος) και το εύρος
**80%** (10ο–90ό εκατοστημόριο). Το εύρος βαθμονομείται σε δεδομένα που το μοντέλο δεν
είδε, ώστε να περιέχει την πραγματική τιμή ~80% των φορών.

**«Θα πέσει;»** Ξεχωριστό μοντέλο εκπαιδεύεται σε πτήσεις που **έχουν ήδη φύγει**, όπου ξέρουμε
αν εμφανίστηκε αργότερα φθηνότερη τιμή. Βγάζει την πιθανότητα να δεις τιμή χαμηλότερη κατά
τουλάχιστον 3 € (ή 3%) πριν την πτήση:
- ≥ 60% → **Περίμενε**
- ≤ 30% → **Αγόρασε τώρα**
- ενδιάμεσα → **Αμφίρροπο**

**Live ανάλυση «παρόμοιες περιπτώσεις».** Για κάθε πτήση τώρα, το σύστημα βρίσκει τις ~60 πιο
παρόμοιες στιγμές σε πτήσεις που έχουν ήδη φύγει και δείχνει τι έγινε σε αυτές: πόσες είδαν
φθηνότερη τιμή, πόσο έπεσε, πόσες έκλεισαν ακριβότερα.

**AI αναλυτής (Claude).** Μετά τα μοντέλα, όλα τα νούμερα (τιμές, προβλέψεις, πιθανότητες, παρόμοιες
περιπτώσεις, φθηνότερη πτήση κάθε μέρας) στέλνονται στο Claude. Αυτό γράφει την ανάλυση: γενική
εικόνα, καλύτερες κινήσεις τώρα, σχόλιο ανά μέρα και ανά πτήση (π.χ. «η πτήση των 08:40 είναι
12 € φθηνότερη»). Το γλωσσικό μοντέλο **δεν μαντεύει τιμές**: έχει οδηγία να χρησιμοποιεί μόνο τους
αριθμούς των μοντέλων και να μην αντιφάσκει με τη σύστασή τους. Έτσι οι αριθμοί μένουν ελέγξιμοι.

**Backtest (έλεγχος ειλικρίνειας).** Σε κάθε εκτέλεση το μοντέλο εκπαιδεύεται στο παλαιότερο
75% των δεδομένων και ελέγχεται στο πιο πρόσφατο κομμάτι, που δεν έχει δει. Συγκρίνεται με την
απλή υπόθεση «η τιμή μένει ίδια». Τα αποτελέσματα φαίνονται στο κάτω μέρος του dashboard.

**Ρεαλιστικές προσδοκίες:** καμία μέθοδος δεν προβλέπει με βεβαιότητα μια τυχαία πτώση
50→58 μέσα στην ίδια μέρα. Οι αεροπορικές αλλάζουν «κουβάδες» ναύλων ανάλογα με τις κρατήσεις.
Αυτό που μπορεί να γίνει καλά, και βελτιώνεται όσο μαζεύονται δεδομένα, είναι η πιθανότητα
πτώσης και το λογικό εύρος τιμής.

## Δομή

```
config.yaml                     διαδρομές, μέρες μπροστά, ρυθμίσεις Apify/μοντέλου
tracker/sources/apify_skyscanner.py   συλλογή από Skyscanner μέσω Apify
tracker/normalize.py            μετατροπή αποτελεσμάτων Skyscanner -> παρατηρήσεις πτήσεων
tracker/storage.py              ιστορικό σε data/observations/YYYY-MM.csv
tracker/model.py                χαρακτηριστικά, μοντέλα, backtest, πρόβλεψη, σύσταση
tracker/ai_analyst.py           AI αναλυτής (Claude) + αυτόματη σύνοψη χωρίς κλειδί
tracker/export.py               docs/data/data.json για το dashboard
tracker/simulate.py             προσομοιωμένα δεδομένα για demo/έλεγχο
docs/                           το dashboard (GitHub Pages)
.github/workflows/track.yml     χρονοπρογραμματισμός κάθε 6 ώρες
```

Τοπικά:

```bash
pip install -r requirements.txt
APIFY_TOKEN=... ANTHROPIC_API_KEY=... python -m tracker.run   # συλλογή + μοντέλο + AI
python -m tracker.run --no-collect        # μόνο μοντέλο
python -m tracker.run --demo              # ξαναφτιάχνει το demo.json
python tests/test_normalize.py
cd docs && python -m http.server          # http://localhost:8000
```

Για άλλες διαδρομές (π.χ. Ηράκλειο) πρόσθεσε στο `routes` του `config.yaml` (`HER`).
